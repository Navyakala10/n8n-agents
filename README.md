# AI Agents using n8n

This project contains 3 AI automation agents built using n8n and OpenAI.

## Agents

### 1. Study Planner Agent
Creates a daily study schedule based on subjects and time.

### 2. Smart Email Assistant
Generates professional emails like leave requests.

### 3. Resume Review Agent
Analyzes resumes and suggests improvements.

## Tools Used
- n8n
- OpenAI API

## How to Use
1. Download JSON file
2. Import into n8n
3. Run workflow
